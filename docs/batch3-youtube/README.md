## Website

Five dedicated `/watch/` pages are included (one pre-existing and four new), with self-canonicals, one long-form iframe, one `VideoObject`, exact upload timestamps and durations, reciprocal episode links, and standard/video sitemap entries.

## YouTube

Approved titles, description links, guest links, playlist memberships, and existing primary channel comments are applied through the owner API where supported. Cards, end screens, thumbnail uploads, and pin-state confirmation require YouTube Studio.

## Caption drafts

The `captions/` directory contains owner exports of the five serving English ASR tracks. Only directly verified proper-name corrections are applied. These are review drafts, not upload-ready files. A human must listen through each episode and verify wording, punctuation, speaker changes, and timing before replacing the serving ASR tracks.
