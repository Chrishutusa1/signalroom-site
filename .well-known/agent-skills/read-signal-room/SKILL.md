# Read Signal Room

1. Fetch https://signalroompodcast.com/llms.txt for the public resource map.
2. Find relevant canonical episode URLs in https://signalroompodcast.com/sitemap.xml or https://signalroompodcast.com/episodes.
3. Read the selected episode page and any available transcript. Do not assume every episode has a transcript.
4. Cite the canonical episode URL. Attribute statements to the identified speaker and preserve uncertainty.
5. Use https://signalroompodcast.com/contact for human inquiries. Reading needs no credentials. Do not submit guest applications or purchases without the user's explicit instruction.

The homepage supports Accept: text/markdown. Other pages remain readable HTML. API discovery is at https://signalroompodcast.com/.well-known/api-catalog.
